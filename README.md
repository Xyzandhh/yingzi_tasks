# 任务 #1：Html 个人简介页面


## 概述

实现一个静态 HTML 个人简介页面，并通过标准 Git 流程（Clone → Commit → Push → Pull Request）提交至指定仓库。

## 需求

### 1. 简介页面

HTML 页面需要包含以下部分：

| 包含内容 |  |
| --- | --- |
| 个人信息 | 仅包含名字
| 技术方向与兴趣 | 硬件/软件
| 掌握的技能 |
| 代表作品 / 项目经历 |可选

约束条件：

- 仅使用 HTML，允许内联 CSS。"静态"指无后端依赖，CSS 动画与过渡效果不受限制。
- 不引入前后端框架。可通过双击在浏览器中正常打开，无外部依赖。
- 排版自行设计

### 2. 提交方式

1. Clone 指定的 GitHub 仓库。
2. 在仓库根目录下以你的昵称创建目录，将 HTML 文件命名为 `index.html` 放入其中。
3. 撰写清晰的 Commit message。
4. Push 分支并发起 Pull Request。

目录结构示例：

```text
.
├── README.md
├── 昵称/
│   └── name_index.html
└── 昵称_2/
    └── name_index.html
```

- 目录名请使用本人昵称，请勿改动他人目录。



## 注意事项

- 仓库为**公开**状态。请勿在页面中包含姓名以外的个人隐私信息（手机号等）。
- 不要给我pr看起来审美非常AI的HTML
