# 任务 #1：HTML 个人简介页面


## 概述

实现一个静态 HTML 个人简介页面，并通过标准 Git 流程（Clone → Commit → Push → Pull Request）提交至指定仓库。

本任务考察：

- 基础 HTML 编写与页面排版能力
- 基于 Git 的团队协作流程（Clone / Commit / Push / Pull Request）熟练度

## 需求

### 1. 简介页面

HTML 页面必须包含以下部分：

| 包含内容 |  |
| --- | --- |
| 受限的个人信息 | 见下
| 技术方向与兴趣 | 硬件/软件
| 掌握的技能 |
| 代表作品 / 项目经历 |可选

约束条件：

- 仅使用 HTML，允许内联 CSS。
- 禁止前端框架，禁止后端。文件必须可通过双击在浏览器中正常打开，无外部依赖。
- 排版自行设计

### 2. 提交方式

1. Clone 指定的 GitHub 仓库。
2. 在仓库根目录下以你的昵称创建目录，将 HTML 文件命名为 `index.html` 放入其中。
3. 撰写清晰的 Commit message。
4. Push 分支并发起 Pull Request。

目录结构示例：

```text
.
├── README.md
├── 昵称/
│   └── index.html
└── 昵称_2/
    └── index.html
```

- 目录名必须为本人昵称，禁止修改他人目录。
- 未按 `./昵称/index.html` 结构放置、或未通过 Pull Request 提交的，一律不予验收。


## 注意事项

- 仓库为**公开**状态。禁止在页面中包含昵称以外的个人隐私信息（真实姓名、手机号、住址、证件号等）。
- Git / GitHub 使用问题须自行查阅官方文档解决。此为本任务考察内容之一。
